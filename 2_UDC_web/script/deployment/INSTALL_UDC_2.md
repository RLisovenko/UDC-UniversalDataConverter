# UDC 2 — установка и запуск на Windows

Комплект предназначен только для веб-проекта `2_UDC_web`, не для Tkinter-версии `1_udc`.

## Размещение

Скачайте или скопируйте весь репозиторий. Поместите все файлы этого комплекта непосредственно в `2_UDC_web/script/deployment/`. Общий файл `udc.ps1` должен лежать рядом с CMD-файлами. Путь может содержать пробелы.

## Подготовка компьютера

Установите Docker Desktop с Linux containers и завершите его первоначальную настройку. Для первого скачивания образов и Python-зависимостей необходим интернет. Python, SQL Server и ODBC на Windows отдельно устанавливать не требуется: они работают внутри контейнеров. Нужен Windows PowerShell 5.1 (штатный компонент Windows).

Для публичного показа дополнительно установите `cloudflared` по официальной инструкции: https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/ . После установки откройте новое окно терминала. Команда `cloudflared --version` должна работать.

В `2_UDC_web/docker/.env` задайте:

```dotenv
MSSQL_SA_PASSWORD='YOUR_OWN_STRONG_PASSWORD'
UDC_VOLUME_NAME=udc_db_data
```

Замените пароль своим: минимум 8 символов и символы как минимум из трёх групп (заглавные, строчные, цифры, специальные). Не публикуйте `.env`. Для существующей установки сохраните прежние пароль и имя тома; изменение имени тома подключит другое хранилище. Скрипты не создают и не перезаписывают `.env`.

Имена контейнеров и порты берутся из исходного compose.yml. Уже существующая другая установка UDC с теми же именами или портами может конфликтовать. Комплект не изолирует несколько установок на одном Docker Engine.

## Первый запуск

Запустите `install_udc_2.cmd` двойным щелчком. Он:

1. Проверяет Docker, при необходимости пытается открыть установленный Docker Desktop и ждёт готовности до 3 минут.
2. Проверяет Compose без вывода пароля.
3. Последовательно собирает SQL Server, образ инициализации и веб-приложение.
4. Запускает полный Compose: подготовку томов, SQL Server, инициализацию базы, веб-приложение.
5. Проверяет JSON `/db-status`: нужны `Connected` и `Converter_UDC`.
6. Открывает локальную страницу.

Первый запуск скачивает большие образы и может занять несколько минут. Данные создаёт существующий SQL-скрипт проекта. Его повторный запуск сохраняет существующие таблицы и данные, но может создавать недостающие объекты и обновлять представление.

## Повторный локальный запуск

Запустите `start_udc_2_local_Docker&SQL.cmd`. Используются уже собранные образы без пересборки и скачивания. Если образов нет, сначала выполните первый запуск. После изменений исходного кода повторите `install_udc_2.cmd` для сборки.

## Показ через интернет

После успешного локального запуска запустите `start_udc_2_tunnel_loc-public.cmd`. Либо после первоначальной установки используйте `start_udc_2_tunnel_loc-public_all.cmd`: локальный запуск и затем туннель в том же окне.

Скопируйте HTTPS-ссылку trycloudflare.com из вывода cloudflared. Проверьте её в инкогнито. Эта ссылка публичная: пользователи могут выполнять доступные приложению действия. Используйте только демонстрационные данные. Компьютер, Docker и процесс туннеля должны продолжать работать; не переводите компьютер в сон. При следующем запуске туннеля адрес может измениться. Это временная демонстрация, а не постоянный хостинг.

Ctrl+C останавливает туннель. Локальные контейнеры продолжают работать. Для их остановки из корня репозитория:

```bash
docker compose -f 2_UDC_web/docker/compose.yml stop
```

## Диагностика

Из корня репозитория:

```bash
docker compose -f 2_UDC_web/docker/compose.yml ps -a
docker compose -f 2_UDC_web/docker/compose.yml logs --tail=60 mssql_2025_dev udc_db_init web_udc
curl.exe --max-time 15 http://localhost:5000/db-status
```

Ожидаются SQL `healthy`, web `Up`, оба init-контейнера `Exited (0)`, JSON `Connected`. Не удаляйте тома для устранения обычной ошибки запуска.

## Проверка комплекта

Выполнена статическая проверка и разбор синтаксиса PowerShell. Реальная установка с пустыми Docker volumes и публичный туннель требуют отдельного испытания на целевом компьютере; при подготовке комплекта контейнеры не запускались.
