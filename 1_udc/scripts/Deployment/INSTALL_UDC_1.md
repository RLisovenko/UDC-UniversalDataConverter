# UDC 1 — установка и запуск на Windows

Комплект предназначен для `1_udc`: это оконная программа Python/Tkinter, работающая с Microsoft SQL Server. Один общий файл `start_udc_1.cmd` готовит окружение, проверяет базу и запускает программу. Второго файла запуска не требуется.

## Что установить заранее

1. Python x64 с компонентами tkinter и pip. Рекомендуется Python 3.12; при установке включите **Add Python to PATH**.
2. Microsoft SQL Server с доступным экземпляром. По умолчанию проект использует `localhost\sql_conv_dev` и авторизацию текущего пользователя Windows. Служба SQL Server должна быть запущена. Для первого создания базы пользователь должен иметь соответствующее разрешение.
3. Microsoft ODBC Driver 18 for SQL Server x64.
4. Интернет для первоначальной установки Python-зависимостей.

Это не автономный установщик системных программ. CMD не устанавливает SQL Server, Python или ODBC и не создаёт Docker-контейнеры: текущая версия `1_udc` настроена на Windows-аутентификацию локального SQL Server.

## Куда скопировать

Клонируйте репозиторий либо перенесите полную папку `1_udc` со всеми её файлами и подпапками. Положите оба файла этого комплекта непосредственно в `1_udc`:

```text
1_udc/
  start_udc_1.cmd
  INSTALL_UDC_1.md
  udc_ui.py
  requirements.txt
  db_con_UDC.py
  utils/
  Sql/
  ...остальные файлы проекта
```

Не переносите `.venv_udc1` с другого компьютера: окружение создаётся заново. Сам комплект не содержит исходники приложения, SQL Server или существующие данные базы. Копирование файлов проекта не переносит содержимое SQL Server; для сохранения существующих данных нужна отдельная резервная копия базы и её восстановление.

## Запуск

Дважды щёлкните `start_udc_1.cmd`. Запускайте от обычного пользователя Windows, которому разрешён доступ к SQL Server.

При первом запуске создаётся `.venv_udc1` и устанавливаются **точные версии** из проектного `requirements.txt`. Если эти версии недоступны в индексе пакетов или несовместимы с Python, установка остановится с сообщением pip; скрипт не заменяет версии молча. Повторная установка выполняется при изменении содержимого requirements.txt.

Параметры SQL берутся из `utils/CONSTANT_config.py`. Если у компьютера другой экземпляр SQL Server, измените `SERVER` в этом файле перед запуском. `db_con_UDC.py` использует авторизацию Windows; настройки пароля SQL в комплект не входят.

Скрипт ждёт доступности SQL Server около минуты. Если базы нет, предлагает ввести `YES`, чтобы создать её и загрузить синтетические демонстрационные данные. Для пустой существующей базы тоже запрашивает `YES`. Для непустой базы выполняет проверку необходимых таблиц и представления, без переинициализации и без добавления демонстрационных строк.

При ошибке создания схемы транзакция откатывается, но созданная база не удаляется. При несовместимой существующей схеме запуск останавливается: автоматической миграции и удаления данных нет.

После успешной проверки открывается окно UDC. Закройте окно приложения для завершения работы, затем нажмите любую клавишу в консоли. Служба SQL Server продолжит работать.

## Проверка после запуска

Откройте просмотр базы и убедитесь, что таблицы доступны. Проверьте экспорт в папку `export`. Импорт добавляет записи в базу: проверяйте его только на тестовых данных. Успешная проверка схемы при старте сама по себе не подтверждает все операции интерфейса.

## Удалённый показ

У `1_udc` нет HTTP-сервера. Обычный Cloudflare-туннель не превращает окно Tkinter в веб-страницу. Показывать эту версию можно через демонстрацию экрана, либо установить её на компьютере зрителя. Для доступа через браузер используйте отдельный проект `2_UDC_web`.

## Если не запускается

- **Python не найден:** проверьте `python --version` в новой консоли, установите Python с PATH.
- **ODBC driver:** установите требуемый драйвер той же разрядности, что Python.
- **Login failed / server not found:** проверьте `SERVER`, службу SQL Server и права текущего пользователя Windows.
- **Invalid object/column:** существующая база имеет другую структуру; скрипт её не переписывает.
- **Ошибка pip:** смотрите имя пакета и сообщение в консоли. Сохраните текст ошибки для проверки requirements.txt.

Комплект работает статически: синтаксис встроенного Python, наличие исходных SQL-файлов и разбиение SQL на пакеты. Полная установка на чистом Windows и выполнение SQL-инициализации этим комплектом не проверялись.
